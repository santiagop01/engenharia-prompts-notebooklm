## 🛠 Engenharia de Prompts e Cicatrizes

No começo eu escrevia prompts simples e a IA respondia de forma fraca.  
Então melhorei os prompts usando técnicas.

**Exemplo de prompt ruim:**  
"Explique prompt engineering"

**Exemplo de prompt bom:**  
"Você é um professor especialista. Explique o que é Engenharia de Prompts e as 5 técnicas mais importantes, com exemplos."

**Dificuldades que tive:**
- As respostas ficavam muito genéricas
- A IA inventava coisas (hallucination)
- As respostas eram muito longas

**Como resolvi:**
- Coloquei um papel para a IA ("Você é um especialista...")
- Pedia para "pensar passo a passo"
- Pedia para usar Markdown e citar fontes

## 📖 Miniguia de Estudo

### Resumo do Assunto
Engenharia de Prompts é a arte de escrever instruções claras e eficazes para Inteligências Artificiais. Quanto melhor o prompt, melhor a resposta.

### Glossário

- **Prompt**: A pergunta ou instrução que você manda para a IA
- **LLM**: Modelo de linguagem grande (ex: GPT, Claude, Gemini)
- **Few-Shot**: Dar exemplos para a IA aprender
- **Chain-of-Thought**: Pedir para a IA pensar passo a passo
- **Hallucination**: Quando a IA inventa informação

### Prompts Reutilizáveis (prontos para usar)

1. **Fazer resumo bom:**
> "Faça um resumo claro e organizado sobre [tópico] usando as fontes."

2. **Melhorar um prompt:**
> "Melhore este prompt para ficar mais eficaz: [cole seu prompt aqui]"

3. **Explicar como criança:**
> "Explique [conceito] como se eu tivesse 12 anos, usando exemplos simples."
